# Instagram Profile Image Design

## Goal

Create a new Instagram profile image from the woman character in the current website hero image while preserving the original hero asset unchanged.

## Source

- Edit target: `public/media/ido-hero-studio-v7-2x.png`
- The character's face, large brown eyes, pink headband, dark French-braid hairstyle and polished 3D illustration style are the identity reference.

## Composition

- Output: 1080×1080 PNG.
- Recompose as a centered head-and-shoulders portrait suitable for Instagram's circular display mask.
- Remove the laptop and other foreground obstructions from the profile composition.
- Keep the complete hair silhouette, headband, face and shoulders comfortably inside the central circular safe area.
- Use a clean warm ivory background derived from the hero image.
- No text, logo, watermark, props or border.

## Identity constraints

- Preserve the same character identity and stylized 3D rendering language.
- Preserve facial proportions, eye colour, brows, skin tone, hairstyle, braid structure and pink headband.
- Use a natural friendly expression; do not redesign the character, change ethnicity, add makeup, or alter age.
- Reconstruct only the areas hidden by the laptop as needed for a believable upper-body portrait.

## Delivery

- Save non-destructively as `public/media/ido-instagram-profile-v1.png`.
- Inspect the full square and a circular-mask preview for face centering, edge safety, artifacts and identity drift.
- Do not replace the website hero image or update website code in this task.
